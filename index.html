Point de vue

La capacité n'est pas le produit.

Le vrai défi de l'IA n'est pas de rendre un modèle impressionnant isolément. Il consiste à concevoir le système autour : le workflow, l'évaluation, les incitations, les interfaces et le modèle opérationnel qui permettent de bien utiliser l'intelligence.

C'est l'espace dans lequel je travaille et j'écris.
