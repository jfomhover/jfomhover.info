# Projets en Français

Placez les descriptions de projets en français dans ce répertoire.

Les fichiers doivent être nommés : `nom-projet.md`

Chaque projet doit inclure le front matter :
```yaml
---
layout: project
title: "Titre du projet"
lang: fr
date: 2026-01-22
technologies: [tech1, tech2]
---
```
